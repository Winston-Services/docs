# Tokens

## Overview

Winston operates four distinct tokens that work together in a cohesive economic system. Each token serves a specific purpose while reinforcing the overall platform value.

## The Four Tokens

### RKL — Rickle (Utility)

The primary cross-chain trading token. Available on 6+ blockchains (Ethereum, BSC, Polygon, Arbitrum, Gnosis, Harmony One). The deepest liquidity pool on TradeTower is RKL/USDT. Used for all core trading pairs and bridge operations across 11 supported chains.

### WIN — Winston (Rewards)

A deflationary rewards token on BSC. 51%+ of total supply is locked forever, creating natural scarcity. An additional 21% was sent to the burn address. Remaining supply appreciates as trading volume increases. Holders receive 26% of all swap fee revenue as proportional rewards based on 30-day rolling average balances.

### WAC — Winston Academy Coin (Learn-to-Earn)

The educational token. Earned through `/quiz` participation, maintaining streaks, hitting accuracy milestones, and `/ask` engagement. Redeemable from the academy treasury for value at AMM rates. Minimum redemption: 1M credits. The treasury is funded by 20% of all swap fees, creating a self-sustaining educational ecosystem.

### AHWA (Governance)

The governance token for platform decisions. One AHWA token equals one vote on BSC. Voting is gasless (sign a message, no transaction required). Three proposal types: Variable (settings changes), Disbursement (treasury allocations), and Content (quiz/fact approval). Used to steer platform direction and community priorities.

## The Economic Loop

The four tokens work together in a self-reinforcing cycle:

1. **Users trade** RKL pairs → generating 3% swap fees
2. **Fees split across four purposes:**
   - 20% funds Academy treasury (grows WAC value)
   - 26% rewards WIN holders (appreciates WIN)
   - 28% supports development via governance disbursements (AHWA-voted)
   - 6.5% recycles to liquidity pools (strengthens RKL pairs)
3. **More trading volume** → bigger treasury → higher redemption rates → more platform value
4. **Governance token holders** (AHWA) direct treasury disbursements
5. **Learners** earn WAC, redeem for value, and grow platform knowledge base

## Key Design Principles

- **Self-sustaining:** Revenue from trading fees funds all four token utilities
- **Alignment:** Each token holder benefits from increased trading volume
- **Accessibility:** Users earn tokens (WAC) by learning, not just spending
- **Decentralization:** Governance decisions made by AHWA holders
- **Deflationary design:** WIN supply constrained, creating appreciation over time
