# Join us in building DeFi

### We're Building DeFi for Everyone — And We Need Your Help

Winston isn't a VC-backed startup with a locked roadmap. It's a community-driven project built from scratch by people who believe decentralized finance should be accessible to everyone — not just crypto natives.

We're looking for developers, thinkers, and builders who want to help shape what DeFi looks like for the next generation of users.

### What We're Building

A complete DeFi ecosystem that runs where people already are — Discord, Telegram, the web. No wallet extensions. No approval transactions. No gas fee confusion. Just simple commands that let anyone trade, earn, learn, and govern.

Under the hood:

* **Custom AMM engine** — Uniswap v2 math (constant-product), built in Node.js with BigInt precision
* **Multi-chain bridge** — Custodial hot wallet pool across 11 blockchains (EVM, UTXO, Tron)
* **L2 state commitments** — On-chain anchoring via Pepecoin OP\_RETURN + Pepinals inscriptions
* **ZK proofs** — PLONK circuits (circom/snarkjs) for Merkle inclusion and balance privacy
* **P2P mesh** — WebSocket nodes with ed25519 identity, state sync, and conflict resolution
* **AI education** — Claude-powered blockchain tutor with quiz scoring and learn-to-earn credits
* **Agent architecture** — Every domain lives in an Agent (EventEmitter + hook lifecycle)
* **REST API** — Express server with JWT/API key auth, OAuth2, full command parity with Discord

### The Tech Stack

* **Runtime:** Node.js (ESM), Discord.js v14
* **Storage:** LevelDB (default) or PostgreSQL via pluggable backend
* **Crypto:** ethers.js v6, TronWeb, BIP39/BIP44/BIP84, AES-256-GCM
* **ZK:** circom 2.0, snarkjs (PLONK), Poseidon hashing (circomlibjs)
* **Deployment:** Docker (single image, env-var tiered)
* **Testing:** 486+ tests across 94 suites

### Why Contribute?

This isn't a "work for free" pitch. The revenue model has a 16.8% development allocation from every swap fee collected. As the platform grows, so does the development fund — governed by community vote through AHWA proposals.

Node operators earn directly from the 7.8% revenue generation pool. Contributors who run nodes get paid for keeping the network healthy.
